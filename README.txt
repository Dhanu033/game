TOGETHER V3 - COUPLE FIGHTERS

1. Extract this folder.
2. Install dependencies: python -m pip install -r requirements.txt
3. Run: python app.py
4. Open http://127.0.0.1:5000 in two browser sessions and join the same room.

Player 1: A/D move, W jump, F punch, G kick, S block.
Player 2: Left/Right move, Up jump, K punch, L kick, Down block.
Mobile users can use the touch buttons.

Note: Rooms are in server memory and reset when the server restarts. This is a local development build, not public hosting.
